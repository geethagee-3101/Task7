# Task 7: First Chart Story — Turning Numbers into a Narrative

## Objective
To create simple charts that answer specific questions and communicate insights using data visualization.

## Dataset
Iris Dataset — contains 150 flower samples from three species: Setosa, Versicolor, and Virginica.

## Tools Used
- Microsoft Excel
- Data Visualization
- Bar Chart, Line Chart, and Pie Chart

## Charts and Key Insights

1. **Average Petal Length by Species — Bar Chart**  
   Virginica has the longest average petal length, while Setosa has the shortest.

2. **Number of Samples by Species — Bar Chart**  
   Each species has 50 samples, showing balanced representation.

3. **Average Petal Measurements — Line Chart**  
   Virginica has the largest average petal measurements, while Setosa has the smallest.

4. **Dataset Sample Share — Pie Chart**  
   Each species represents approximately 33.3% of the dataset.

## Overall Narrative
The charts show that the Iris dataset contains equal numbers of samples for all three species. However, their petal measurements differ significantly. Setosa has the smallest average petals, Virginica has the largest, and Versicolor falls between them. These visualizations help communicate patterns and comparisons clearly.

## Interview Questions

**1. When would you choose a bar chart over a line chart?**

A bar chart is suitable for comparing values across different categories. A line chart is better for showing trends or changes over time.

**2. Why are pie charts often discouraged in professional reporting?**

Pie charts can make it difficult to compare similar-sized slices accurately. Bar charts often communicate comparisons more clearly.
